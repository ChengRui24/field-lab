No device

无设备对照

没有手表时，用主观方法校准强度。谈话测试是首选；鼻吸测试帮你守 LT1（lactate threshold 1，第一乳酸阈）；RPE（rating of perceived exertion，自觉劳累）作交叉验证。本页没有输入框——对照着跑即可。

口令卡

给队员的现场口令。跑、骑时让他说一句完整的话（大约 10–15 个字）：

队员的状态 口令
能舒服地说完整的句子 轻松有氧，保持
能说，但说得不舒服、要停下来换气 轻松课：放慢
需要张嘴喘，只能说几个词 放慢（只有计划好的强度课才到这里）

轻松有氧 = 第一通气阈 / 第一乳酸阈（VT1 / LT1）以下，常用五区心率里的 Z1–Z2。依据见下方谈话测试（Reed & Pipe 2014；Foster 2008）。

谈话测试 Talk Test

Reed & Pipe 2014 综述：在运动员、健康成人和心血管病患者中，能舒服说话时多在 VT1（ventilatory threshold，第一通气阈）或乳酸阈以下，不能时多已超过；走、跑、骑、椭圆机、台阶机之间结果一致。说话开始不舒服（「说不准」）时大约在 VT1 附近（Foster 2008）；明确答「不能」时接近 VT2（Recalde 2002，训练者样本）。ACE（American Council on Exercise，美国运动委员会）2025 年把它作为三区强度模型的无设备方法。这是群体层面的对应，个人误差可能不小，是无设备时的首选，不是精确测定。

  1. 跑、骑或爬坡时，试着说一句完整的话（大约 10–15 个字）。游泳不便说话时改用鼻吸或 RPE。
  2. 对照下表：能舒服说完整句子，就在轻松有氧范围；说话开始不舒服，已到 VT1 附近；说不出完整句子、只能蹦几个词，已接近或超过 VT2。
状态 对应
能舒服地说完整句子 < VT1 / LT1（Z1–Z2，轻松有氧）
能说，但不舒服，说几句要换气 ≈ VT1 到 VT2 之间
说不出完整句子，只能蹦几个词 接近或 > VT2 / LT2

鼻吸测试

  1. 用鼻子吸、鼻子呼，全程不张嘴。能维持就还在 LT1 以下。
  2. 一旦必须张嘴，强度就已经过了 LT1。
状态 对应
能用鼻子全程吸气呼气（不张嘴） < LT1
必须张嘴呼吸 > LT1

RPE 自觉劳累（CR-10，0–10）

  1. 问自己：这强度有多费？用和训练负荷页同一张改良 CR-10 量表（Foster 2001）：3 分「中等」，4 分「有点吃力」，5–6 分「吃力」，10 分「极限」。
  2. 新手容易判断不准，请同时用谈话测试对照，不要只凭「感觉还能再快」。
RPE 感觉（改良 CR-10） ACE 三区
0–2 休息 / 非常非常轻松 / 轻松 热身、恢复
3–4 中等 / 有点吃力 区 1：< VT1，能舒服说话
5–6 吃力 区 2：VT1–VT2，说话不舒服
7–10 非常吃力 / 极限 区 3：≥ VT2，只能蹦几个词

注意事项

  1. 新手 RPE 判断偏差较大，容易低估或高估。请同时用谈话测试交叉验证，不要只凭「感觉还能再快」。
  2. 训练者 对 RPE 的感知更准，训练中可以心率为主、RPE 为辅。无表日仍以谈话测试守 Z2。心率区不要跨跑步、骑行、游泳互抄。
  3. 不要用 SpO₂ 健康人在 LT1/LT2 时血氧通常仍在 96–98%，看不出拐点；接近 VO₂max 才可能轻度低氧。消费级手表运动中血氧（SpO₂，peripheral oxygen saturation）一致性差（CCC，concordance correlation coefficient < 0.7），不能作为阈值依据。血氧的实用场景是高原：<90% 需要警惕。
  4. 手表算法 手表自带的「有氧阈值 / 训练效果」多半基于心率变异性与配速，不是血氧。可以参考，但现场仍以谈话测试或实测 LTHR（lactate threshold heart rate，乳酸阈心率）为准。
